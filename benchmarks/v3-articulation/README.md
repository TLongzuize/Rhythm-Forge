For the orchestral take use the [existing local OGG](/tmp/rf-grammar-gate-audio.0kyNGL/nutcracker.ogg) or download the [same Kevin MacLeod recording](https://github.com/librosa/data/blob/main/audio/Kevin_MacLeod_-_P_I_Tchaikovsky_Dance_of_the_Sugar_Plum_Fairy.ogg).

1. Enable **Practice mode** under **Settings → Input & timing → Gameplay Lab** and set the two loop percentages. Use one speed, playback rate, and audio offset across takes.
2. In **Chart Generator**, load the full recording, click **Generate all difficulties**, and choose **Edit** to open the chart importer.
3. In **Chart Editor**, choose **Import JSON** for the numbered take, then **Preview → Start now**. After one pass, use **Esc → Quit** and reopen the editor for the next take.
4. Give each take a 1–5 rating for rhythm, flow, difficulty fit, and enjoyment. Note any timing problem and its approximate timestamp. Ties and no preference are valid.

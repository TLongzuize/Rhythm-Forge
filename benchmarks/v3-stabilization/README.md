1. In **Settings → Input & timing → Gameplay Lab**, enable **Practice mode** and enter the loop percentages. Keep your normal latency calibration and use the same scroll speed for each take.
2. Load the full recording in **Chart Generator**, choose **Generate all difficulties**, then **Edit**. In the editor select **Import JSON → Preview → Start now**. Press **Esc → Quit** after playing the excerpt once and reopen the editor for the next take.
3. Record each take's sync, pattern flow, and enjoyment. Mark whether any hold entrance or release feels hard to hear or uncomfortable to play. Record the timestamp where possible. Ties are valid.
